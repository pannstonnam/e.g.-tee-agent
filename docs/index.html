# Thesis & Q-Condition ของหุ้นแต่ละตัว

### 1. NVIDIA Corporation (NVDA)
* **Original Thesis 3 ข้อ:**
  1. **Full-Stack Ecosystem Moat:** ไม่ได้ขายแค่ชิป GPU แต่ขายระบบครบวงจร (CUDA, NVLink, Networking run rate $60B) เกิด Network Effect และ Developer Lock-in ที่แข็งแกร่งที่สุดในอุตสาหกรรม
  2. **High Return on Capital & Cash Flow:** มีกระแสเงินสดจากการดำเนินงานระดับ $48B พร้อมโปรแกรมซื้อหุ้นคืน $80B มีอำนาจกำหนดราคาและประสิทธิภาพการใช้เงินทุนสูงมาก
  3. **Scale Economies Shared in Compute:** การเร่งประสิทธิภาพต่อวัตต์และหน่วยความจำอย่างต่อเนื่อง ทำให้ต้นทุนต่อ Token ต่ำลงเรื่อยๆ ช่วยขยาย TAM ไปสู่ Sovereign Cloud, Enterprise และ Physical AI (Robotics/Omniverse)
* **Q-Condition (เงื่อนไขสั่งขาย):**
  * ส่วนแบ่งตลาด (Market Share) ในฝั่งประมวลผล AI สูญเสียอย่างถาวรจนต่ำกว่า 50% ให้แก่ Custom ASICs หรือคู่แข่ง
  * อัตรากำไรขั้นต้น (Gross Margin) ลดลงอย่างมีนัยสำคัญจนต่ำกว่า 55% สื่อถึงการสูญเสียอำนาจกำหนดราคาและกลายเป็นสินค้าโภคภัณฑ์

### 2. Amazon.com, Inc. (AMZN)
* **Original Thesis 3 ข้อ:**
  1. **Prototypical Scale Economies Shared:** ต้นแบบโมเดลธุรกิจที่นำประหยัดเชิงขนาด (Scale) จาก AWS และ Retail ไปลดราคาและเพิ่มประสิทธิภาพให้ลูกค้า เกิด Flywheel ที่ดึงดูดปริมาณการใช้งานใหม่ๆ อย่างไม่จบสิ้น
  2. **Vertical Silicon Integration:** การพัฒนาชิปประมวลผลของตัวเองอย่าง Trainium และ Inferentia (มียอดผูกพัน >$225B) ช่วยลดต้นทุนฮาร์ดแวร์ระยะยาวของ AWS เพิ่มอัตรากำไรและมอบทางเลือกที่คุ้มค่าให้แก่ลูกค้า
  3. **Enterprise Cloud Platform Standard:** AWS เป็นฐานรากสำคัญของข้อมูลองค์กร ทำให้ได้ประโยชน์โดยตรงจากการเปลี่ยนผ่านเข้าสู่ยุค AI Workflow และ Agentic Applications
* **Q-Condition (เงื่อนไขสั่งขาย):**
  * AWS สูญเสียส่วนแบ่งทางการตลาดระบบคลาวด์อย่างต่อเนื่องติดต่อกันเกิน 8 ไตรมาส
  * ผู้บริหารละทิ้งปรัชญา Scale Economies Shared โดยหันไปเพิ่มราคาเพื่อสร้างกำไรระยะสั้นจนกระทบความพึงพอใจและการยึดติดของลูกค้า

### 3. Taiwan Semiconductor Manufacturing Co. (TSM)
* **Original Thesis 3 ข้อ:**
  1. **De Facto Foundry Monopoly:** ครอบครองส่วนแบ่งการผลิตชิปขั้นสูง (Leading-Edge Node) กว่า 90% ของโลก เป็นการผูกขาดเชิงโครงสร้างที่ต้องใช้เงินทุนและเทคโนโลยีระดับสูงจนคู่แข่งเลียนแบบไม่ได้
  2. **Shared Scale in Manufacturing:** เงินลงทุน CapEx ระดับมหาศาลทำให้เกิด Economy of Scale ในการผลิต ซึ่งถูกส่งผ่านเป็นต้นทุนต่อทรานซิสเตอร์ที่ถูกลงให้กับลูกค้ารายใหญ่ (NVDA, AAPL, AMD)
  3. **Valuation Disconnect:** ซื้อขายที่ระดับ P/E เพียง 25 เท่า โดยมีอัตรา PEG ต่ำกว่า 1.0 บนคาดการณ์การเติบโตของกำไร 30% ต่อปี ซึ่งต่ำกว่าคุณค่าเชิงโครงสร้างที่แท้จริง
* **Q-Condition (เงื่อนไขสั่งขาย):**
  * พ่ายแพ้เทคโนโลยีการผลิตชิปขั้นสูง (Process Node Leadership) ให้แก่คู่แข่งอย่าง Intel หรือ Samsung ติดต่อกันเกิน 2 เจเนอเรชัน
  * อัตรากำไรขั้นต้น (Gross Margin) ตกต่ำลงอย่างยั่งยืนจนต่ำกว่า 45%

### 4. Microsoft Corporation (MSFT)
* **Original Thesis 3 ข้อ:**
  1. **Unrivaled Enterprise Distribution:** ฐานลูกค้าองค์กรผ่าน Office 365 และ Azure ที่แข็งแกร่งที่สุดในโลก ทำให้การปรับเพิ่มฟีเจอร์ AI ทำได้ทันทีผ่านช่องทางเดิมโดยมีต้นทุนการได้มาซึ่งลูกค้า (CAC) ต่ำมาก
  2. **Massive AI Monetization Scale:** รายได้ที่เกี่ยวข้องกับ AI วิ่งด้วย Run Rate สูงถึง $37B แสดงถึงการประยุกต์ใช้งานจริงในเชิงพาณิชย์ และได้รับการยืนยันจาก Goldman Sachs ว่า EPS จะเร่งตัวเกิน 20% ภายในปี FY29
  3. **Capex Discipline & Cloud Re-acceleration:** การขยาย Azure ทำได้ดีโดยคงเป้างบ CapEx ปี 2026 ไว้ตามเดิม มอบ Margin of Safety และความเสถียรของกระแสเงินสด
* **Q-Condition (เงื่อนไขสั่งขาย):**
  * อัตราการเติบโตของ Azure ต่ำกว่าคู่แข่งหลักในอุตสาหกรรมอย่างมีนัยสำคัญติดต่อกัน 4 ไตรมาส
  * เกิดการยกเลิกใช้งาน (Churn) ของซอฟต์แวร์หลักในฝั่งองค์กรจากการถูก Disintermediate โดยโมเดล AI ภายนอกอย่างถาวร
